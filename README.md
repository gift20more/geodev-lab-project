              GeoDev Lab Project

               Project Title

GIS-Based Assessment of Water Availability and Accessibility in Malawi

           About the Project

This project focuses on the use of Geographic Information Systems
(GIS) to assess the availability and accessibility of water sources.

The project is related to Water Resources Engineering, WASH, GIS,
Remote Sensing and environmental management.

         Project Objectives

- Map available water sources.
- Analyse access to water sources.
- Identify areas with potentially poor water accessibility.
- Use spatial data to support water-resource planning.
